# CLAUDE.md

Guidance for Claude Code (and other AI assistants) when working in this repository.

## Conventions

- When generating **commit messages** and **pull request descriptions**, sign the
  generated text as:

  > Generated by Michal Dengusiak & Claude Code

## Testing

- Follow the two-tier test method documented in `TESTING.md`: pure-managed
  **unit tests** in `Testing/SAM.OCCT.UnitTests` and native-gated
  **integration tests** in `Testing/SAM.OCCT.IntegrationTests`.
- Use xUnit, the `Method_State_Expected` naming convention, and Arrange/Act/Assert.
- Add/extend unit tests for any managed change; add integration tests when native
  OCCT behaviour changes. Every new `.cs` file needs the SPDX header.
